# AI Assistant for Personalized Career Pathway Exploration in Universities

## Description
This project aims to develop an AI-powered assistant that helps university students explore personalized career pathways based on their interests, academic background, alumni career trajectories, and labor market trends.

## Features
- Personalized Career Recommendations
- Skill Gap Analysis
- Course & Certification Suggestions
- Career Roadmap Generation
